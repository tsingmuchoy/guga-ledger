# 咕嘎记账本 Guga Ledger 💰🐧

一款深灰配琥珀的极简安卓记账本：一级分类、点几下记一笔，所有数据只存手机本地，
不联网、不上传、不收集。

> 由 **清木** 与 AI 助手「小咕嘎」共同打造的个人项目。

## ✨ 功能

- ✍️ **快速记账**：金额 / 分类 / 日期 / 备注，一屏完成
- 🗂️ **一级分类**（不搞繁琐的子分类）：
  - 支出：餐饮、交通、房租、水费、电费、燃气费、话费网费、购物、日用品、娱乐、游戏、会员订阅、学习、医疗、运动健身、旅游、人情往来、宠物、其他支出
  - 收入：工资、生活费、兼职、红包、退款、其他收入
- 📅 **按天分组流水**：每日小计一目了然
- 📊 **月度总览**：本月结余 / 支出 / 收入 + 分类统计条
- ✏️ 点按编辑、长按删除已记账目
- 🔒 **纯本地**：SQLite 存在应用私有目录，无网络权限

## 📦 安装

到本仓库的 **Releases** 下载最新 APK 直接安装（安卓 8.0+）。覆盖安装不丢数据；请勿卸载重装（数据会清空）。

## 🔨 构建

本项目没有用 Gradle（开发机上 Gradle 守护进程无法启动），使用 Android 构建工具手动管线打包，
**不依赖任何第三方库**——纯 Android 框架（Java）实现。

准备：JDK 17 + Android SDK（platform 34 / build-tools 34.0.0），然后：

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_SDK=/path/to/android-sdk
./build.sh 4 1.3.1   # 参数：versionCode versionName
```
